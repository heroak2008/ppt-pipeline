# 模板容量（capacity）评审指导文档

> 用途：指导人工/内网 AI 工具评审模板候选页的 `capacity` 填写质量。
> 背景：capacity 是生成系统的“防溢出约束”——每个模板区域最多能装多少内容。
> 填大了 → 生成时溢出/破版；填小了 → 浪费版面、内容被截断。**目标是"略紧的安全上限"**。

---

## 1. capacity 是什么

模板候选页在审核表单中填写的 JSON，描述该页版式的**布局区域**和**每个区域的容量上限**：

```json
{
  "layout": {
    "title_area": [0.65, 0.42, 11.9, 0.55],
    "content_areas": [
      [0.65, 2.0, 3.85, 3.9],
      [4.75, 2.0, 3.85, 3.9],
      [8.85, 2.0, 3.85, 3.9]
    ]
  },
  "capacity": {
    "title_max_chars": 26,
    "column_count": 3,
    "column_title_max_chars": 10,
    "column_body_max_chars": 60
  }
}
```

- `layout`：区域坐标 `[x, y, 宽, 高]`，单位**英寸**（16:9 页面宽 13.333 × 高 7.5）。对照页面详情的"布局示意图"填写。
- `capacity`：每个区域的内容上限（字数/数量/行数），命名规则：`{区域}_{指标}`。

## 2. 容量指标的估算方法

### 2.1 字数上限（`*_max_chars`）——最常用

**基准公式**（MiSans 等无衬线中文字体的经验值）：

```
单行可容纳中文字数 ≈ 区域宽度(英寸) × 字号系数
  字号 26pt：每英寸约 3.5 字
  字号 16pt：每英寸约 5.5 字
  字号 11pt：每英寸约 8 字
  字号 9pt： 每英寸约 10 字
总容量 = 单行字数 × 该区域实际行数（区域高度 ÷ 行高，行高 ≈ 字号 × 1.4）
```

**更快的实操方法（推荐）**：看范例页该区域**实际装了多少字**，取 `实际字数 × 1.15`（留 15% 余量），不用算公式。

| 区域类型 | 典型上限（16:9，11pt 正文） |
| --- | --- |
| 页面标题 | 20–28 字 |
| 副标题/导语 | 40–60 字 |
| 栏目标题（三栏页） | 8–12 字 |
| 栏目正文（三栏页） | 50–70 字 |
| 整页总文字 | 一般不超过 300 字 |

### 2.2 数量上限

- `column_count`：栏数（布局图上一眼可数）
- `phase_count` / `milestone_per_phase_max`：路线图的阶段数/每阶段里程碑数
- `item_count_max`：列表/卡片区最多几条（看范例页装了几条，行间距是否已紧张）
- `row_count_max`：表格页最多几行

### 2.3 图表容量（图表页）

```json
{"capacity": {"chart_type": "bar", "series_max": 4, "category_max": 12}}
```
- `series_max`：图例最多几个系列（多了挤不下）
- `category_max`：横轴最多几个类目（柱图超过 12 根就拥挤）

## 3. 评审检查清单（逐条过）

对每一个模板候选的 capacity，检查：

**布局区域**
- [ ] `layout` 各区域不重叠（肉眼对照布局示意图）
- [ ] 区域都在页面边界内（x+宽 ≤ 13.333，y+高 ≤ 7.5）
- [ ] 页眉/页脚/Logo 区没有被算进 content_areas

**容量数值**
- [ ] 每个 capacity 键都能在布局示意图上找到对应区域（无凭空指标）
- [ ] 字数上限 ≈ 范例页实际字数 × 1.15，偏差不超过 ±30%
- [ ] 栏数/阶段数等数量指标与示意图一致
- [ ] 正文字号低于 9pt 的区域 → 直接不允许（公司规范最小字号，容量写 0 或标记不可用）

**语义一致性**
- [ ] 容量键的命名与页面类型匹配（三栏页用 `column_*`，路线图用 `phase_*`，不要混用）
- [ ] 同一类型词表下多个模板候选的容量字段名一致（如都叫 `column_body_max_chars`）

**整体合理性**
- [ ] 按容量装满后，整页文字总量 ≤ 300 字（超过说明上限估松了）
- [ ] 与规范文档（design-spec markdown）不冲突：字号下限、禁用色等

## 4. 常见错误（评审时重点抓）

| 错误 | 后果 | 例子 |
| --- | --- | --- |
| 上限照抄范例实际字数（没留余量） | 稍长的内容就溢出 | 范例标题 24 字 → 上限写成 24，应为 27 |
| 余量留太大 | 生成内容被截断看不出 | 栏正文实际 50 字 → 上限写 120 |
| 布局区域重叠 | 生成时两个区域抢位置 | 第三栏 x=8.85 宽 3.85，第二栏误写 x=4.0 宽 5.0（重叠 1.15"） |
| 把装饰元素区域算进内容区 | 生成文字压到色块/图标上 | 顶部 accent bar 区域被划进 title_area |
| 坐标单位用错（写成像素或 EMU） | 完全错位 | layout 写 [914400, ...]（这是 EMU，应是英寸） |
| 容量键名各页不一致 | 生成系统无法通用读取 | A 页写 `col_body_max`，B 页写 `column_body_max_chars` |

## 5. 各页面类型的 capacity 模板（复制后改数值）

**封面 cover**
```json
{"layout": {"title_area": [0.65, 1.5, 11.9, 1.2], "subtitle_area": [0.65, 2.8, 11.9, 0.6]},
 "capacity": {"title_max_chars": 20, "subtitle_max_chars": 40, "date_line": true}}
```

**三栏 three-pillars**
```json
{"layout": {"title_area": [0.65, 0.42, 11.9, 0.55],
            "content_areas": [[0.65, 2.0, 3.85, 3.9], [4.75, 2.0, 3.85, 3.9], [8.85, 2.0, 3.85, 3.9]]},
 "capacity": {"column_count": 3, "column_title_max_chars": 10, "column_body_max_chars": 60}}
```

**路线图 roadmap**
```json
{"layout": {"title_area": [0.65, 0.42, 11.9, 0.55], "timeline_area": [0.65, 1.8, 12.0, 4.8]},
 "capacity": {"phase_count": 3, "milestone_per_phase_max": 5, "phase_title_max_chars": 12}}
```

**数据看板 kpi-board**
```json
{"layout": {"title_area": [0.65, 0.42, 11.9, 0.55], "kpi_area": [0.65, 1.6, 12.0, 1.6],
            "detail_area": [0.65, 3.4, 12.0, 3.2]},
 "capacity": {"kpi_card_count": 4, "kpi_label_max_chars": 8, "detail_max_chars": 120}}
```

**对比页 comparison**
```json
{"layout": {"title_area": [0.65, 0.42, 11.9, 0.55],
            "left_area": [0.65, 1.8, 5.9, 4.8], "right_area": [6.85, 1.8, 5.9, 4.8]},
 "capacity": {"side_title_max_chars": 10, "side_body_max_chars": 120, "side_point_count": 5}}
```

## 6. 给内网 AI 工具的检查提示词

把下面这段连同**待审的 capacity JSON** 和**页面布局示意图说明**一起喂给内网 AI：

```text
你是 PPT 模板容量评审员。请检查下面的模板候选页 capacity JSON。

检查规则：
1. layout 坐标单位是英寸，16:9 页面宽 13.333、高 7.5；各区域不得重叠、不得越界。
2. 每个 capacity 键必须对应 layout 中的真实区域或本页明确的结构元素（栏/阶段/卡片）。
3. 字数上限应约为该页实际内容的 1.15 倍（允许 ±30%）；超过 1.5 倍判"过松"，低于实际值判"过紧"。
4. 整页按容量装满后总字数不得超过 300 字。
5. 容量键命名必须与同类型其他模板一致（三栏页统一 column_*，路线图统一 phase_*）。
6. 正文区域容量对应的字号不得小于 9pt。

输出格式：
- 结论：通过 / 需修改
- 问题列表：每条注明字段名、问题、建议值
- 修正后的完整 JSON（如有修改）

页面类型：{slide_type}
页面实际文本内容：{该页提取的文本}
布局示意图描述：{各形状位置}
capacity JSON：{待审 JSON}
```

## 7. 评审节奏建议

- 不用一次全审：**每种页面类型先精审 1 个**（打成样板），其余同类型模板对照样板快速过
- 每审完一类，用检索验证：搜该类型关键词 → 命中模板 → 容量 JSON 可读 → 通过
- 容量偏差积累到影响生成效果时（生成页频繁溢出/太空），回来整体收紧一轮
